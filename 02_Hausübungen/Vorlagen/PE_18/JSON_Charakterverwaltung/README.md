# PE18 – JSON-Charakterverwaltung

Das Projekt enthält nur die vorbereitete Projektstruktur, die Klassen,
die Service-Methodensignaturen und deren Verknüpfung in `Program.cs`.

Die eigentliche Logik wird anhand der separaten Aufgabenstellung umgesetzt.

## Projektstruktur

```text
PE18_JSON_Charakterverwaltung/
├── Data/
│   └── charaktere.json
├── Models/
│   ├── Charakter.cs
│   └── Gegenstand.cs
├── Services/
│   └── CharakterService.cs
├── Program.cs
└── PE18_JSON_Charakterverwaltung.csproj
```
